# jetztaberPROMPT! brand assets

Primary palette:

- International Orange: `#FF4F00`
- Charcoal: `#171717`
- Warm White: `#FAF7F2`
- White: `#FFFFFF`

Use `jetztaber-mark.svg` for compact placements, avatars, and favicons. Use
`jetztaber-wordmark.svg` wherever there is enough horizontal room. Reversed variants
have a charcoal background and are intended for dark placements.

The wordmark lettering is converted to vector outlines, so no font installation is
required. Keep clear space around the mark equal to at least the width of its
exclamation point.

Raster exports are included for quick use. Prefer SVG in web and print layouts.
